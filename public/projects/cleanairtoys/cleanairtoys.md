## 📝 About the Project (เกี่ยวกับโปรเจกต์)

โปรเจกต์นี้เป็นระบบสร้างหน้าเว็บไซต์แบบไดนามิก โดยมีระบบหลังบ้านให้ผู้ดูแลระบบ (Admin) สามารถกดสร้างรายการหน้าเว็บไซต์และจัดเตรียมรหัสชิ้นงาน (`page_code`) สำหรับสินค้า จากนั้นนำลิงก์ของหน้าเว็บไซต์ที่สร้างขึ้นไปแปลงเป็น QR Code ผ่านบริการภายนอกเว็บไซต์แล้วนำ QR Code นั้นมาแปะติดกับตัวสินค้า

**จุดเด่นสำคัญของระบบ:**
- **การปรับแต่งโดยผู้ใช้เพียงครั้งเดียว (One-time Customization by User):** เมื่อลูกค้าที่ซื้อสินค้าทำการสแกน QR Code เป็นครั้งแรก จะสามารถเข้าสู่หน้าเว็บไซต์เพื่อปรับแต่งชิ้นงานพิเศษเฉพาะตัวได้ด้วยตัวเอง (เช่น เลือกเทมเพลต จัดวางข้อความ หรือแนบสื่อต่าง ๆ) **และเมื่อกดปุ่มบันทึกยืนยันแล้ว ระบบจะทำการล็อคหน้าเว็บไซต์นั้นทันที และจะไม่สามารถกลับมาแก้ไขดีไซน์หรือข้อมูลใด ๆ ได้อีก** (การสแกน QR Code ในครั้งถัดไปจะเป็นการแสดงผลชิ้นงานที่เสร็จสมบูรณ์แล้วเท่านั้น)
- **ระบบเทมเพลตมาตรฐาน (Standardized Template System):** เพื่อให้ชิ้นงานออกมาสวยงามและรองรับหน้าจอมือถือ (Responsive) อย่างสมบูรณ์ การตกแต่งหน้าเว็บไซต์จะ **ไม่สามารถลากวางตำแหน่งอิสระ (No Free Drag-and-Drop)** ได้อีกต่อไป แต่จะมี **เทมเพลต (Templates)** มาตรฐานให้ผู้ใช้งานเลือกสรรแทน โดยระบบจะบังคับจัดวางองค์ประกอบทั้งหมดให้อยู่กึ่งกลางอย่างเป็นระเบียบตามหลัก UI/UX

## 🔄 System Workflow (ขั้นตอนการทำงานของระบบ)

1. **สร้างและเตรียมหลังบ้าน (Admin Initial Setup):** แอดมินเข้าสู่ระบบหลังบ้าน (Admin Dashboard) เพื่อกดสร้างรายการหน้าเว็บใหม่ ระบุรหัสเว็บ (`page_code`), หมวดหมู่สินค้า และหมายเลขคิว
2. **แปลงลิงก์เป็น QR Code (QR Code Generation & Placement):** แอดมินนำลิงก์หน้าเว็บที่ระบบสร้างให้ ไปสร้างเป็น QR Code จากเว็บไซต์ภายนอก หรืออัปโหลดรูปภาพ QR Code เก็บไว้ในระบบ แล้วพิมพ์ QR Code แปะติดลงบนสินค้าจริง
3. **ลูกค้าสแกนเพื่อตกแต่งครั้งแรก (First-time Customer Scan):** ลูกค้าสแกน QR Code บนสินค้า เพื่อเข้าสู่หน้าปรับแต่งชิ้นงานของตนเอง
4. **เลือกเทมเพลตและปรับแต่งชิ้นงาน (Template Selection & Decoration):** ผู้ใช้งานตกแต่งหน้าเว็บโดยเลือกจาก **เทมเพลตมาตรฐาน (Template A, B, C, D)** ที่ระบบเตรียมไว้ให้ (ไม่มีการลากวางอิสระ) สามารถเพิ่มข้อความ รูปภาพ/โมเดล 3D และเสียงเพลงประกอบได้
5. **บันทึกและล็อคชิ้นงานถาวร (Save & Permanent Lock):** เมื่อลูกค้าตกแต่งเสร็จและกดยืนยันการบันทึก ระบบจะบันทึกข้อมูลลงฐานข้อมูลและ **ล็อคสิทธิ์การแก้ไข (Lock Edit Privilege)** ทันที จะไม่สามารถกลับมาแก้ไขได้อีกเป็นครั้งที่สอง
6. **การสแกนและแสดงผลจริง (Permanent Live View):** เมื่อลูกค้าหรือผู้คนที่สนใจสแกน QR Code ตัวเดิมในอนาคต ระบบจะแสดงผลหน้าชิ้นงานล่าสุดที่ถูกบันทึกไว้ในรูปแบบหน้าเว็บสำเร็จรูปที่สวยงาม

## 🛡️ Admin Dashboard Capabilities (ความสามารถของระบบหลังบ้าน Admin)

ระบบหลังบ้านถูกออกแบบมาเพื่ออำนวยความสะดวกให้แอดมินในการบริหารจัดการชิ้นงานของลูกค้าได้อย่างครบวงจร ดังนี้:

1. **การจัดการรายการหน้าเว็บไซต์ทั้งหมด (Custom Pages Management):**
   - ดูตารางรายการหน้าเว็บทั้งหมด พร้อมข้อมูลรหัสหน้าเว็บ (`page_code`), รูปภาพ QR Code, หมวดหมู่สินค้า (เช่น พวงกุญแจ, ที่รองแก้ว), หมายเลขคิว, วันที่สร้าง และเวลาที่แก้ไขล่าสุด
   - **แสดงสถานะการล็อคชิ้นงาน (Lock Status Badge):** แสดงป้ายสถานะว่าชิ้นงานถูกลูกค้าตกแต่งและล็อคแล้วหรือยัง (**🔒 ล็อค** หรือ **🔓 กำลังตกแต่ง**) พร้อมฟังก์ชันคลิกเพื่อปลดล็อคสิทธิ์ให้ลูกค้าตกแต่งใหม่ได้ในกรณีพิเศษ (Reset Lock)
   - **ระบบค้นหาและตัวกรอง (Search & Filter):** ค้นหาหน้าเว็บได้จากรหัสเว็บ, ลิงก์ QR Code หรือข้อมูลคิว พร้อมตัวกรองตามหมวดหมู่สินค้าและการจัดเรียง (ล่าสุด/เก่าสุด)
2. **เครื่องมือจัดการด่วน (One-click Action Tools):**
   - **ปุ่มคัดลอกรหัส (Copy Code):** คัดลอกรหัส `page_code` ได้ทันทีในคลิกเดียว
   - **ปุ่มคัดลอกลิงก์ (Copy Link):** คัดลอกลิงก์หน้าเว็บเต็มรูปแบบ (URL) สำหรับส่งให้ลูกค้าหรือนำไปสร้าง QR Code
   - **ปุ่มคัดลอกลิงก์ตกแต่ง (Copy Customize Link):** คัดลอกลิงก์หน้าสำหรับปรับแต่งสินค้าโดยตรง (`customize.php`)
   - **ปุ่มดูตัวอย่าง (Preview):** เปิดดูหน้าเว็บจริงของลูกค้าในแท็บใหม่
   - **ปุ่มแก้ไข (Edit) และลบ (Delete):** เข้าแก้ไขโครงสร้างหรือลบหน้าเว็บออกจากระบบ
3. **ระบบสิทธิ์เหนือสุดของแอดมิน (Superuser Override):**
   - แอดมินมีสิทธิ์เหนือสุด สามารถกดเข้าไปแก้ไขชิ้นงานนั้นได้เสมอจากระบบหลังบ้าน (`create_custom_page.php`) แม้ว่าชิ้นงานจะถูกลูกค้าล็อคไปแล้วก็ตาม
4. **จัดการข้อมูลสินค้าและคิว (Product & Queue Management):**
   - สามารถระบุหมวดหมู่สินค้าและหมายเลขคิวการผลิต/จัดส่ง เพื่อความเป็นระเบียบในการติดตามงาน
5. **การจัดการรูปภาพ QR Code (QR Code Assets):**
   - อัปโหลดหรือแนบลิงก์รูปภาพ QR Code พร้อมระบบคลิกที่รูปภาพในตารางเพื่อขยายดู QR Code ขนาดเต็มได้ทันที
6. **การสร้างและตั้งค่าโครงสร้างเว็บ (Page Creation & Editor):**
   - สร้างหน้าเว็บใหม่พร้อมตั้งค่าสีพื้นหลัง, ลำดับบล็อกข้อความ, รูปภาพ, โมเดล 3D และเสียงเพลง เพื่อจัดเตรียมไว้เป็นค่าเริ่มต้นให้ลูกค้า

## ⚠️ Golden Rules & Constraints (กฎเหล็กในการพัฒนา)

- **กฎการจัดการฐานข้อมูล (Database Rule):** **ห้าม AI นำข้อมูลเข้า (Insert) หรือสร้าง/แก้ไขตารางฐานข้อมูล (Create/Alter Table) ด้วยตัวเองโดยตรงผ่านระบบรันคำสั่งเด็ดขาด!** หากจำเป็นต้องปรับปรุงฐานข้อมูล AI จะต้องอธิบายและแจ้งผู้ใช้งานก่อนเสมอ พร้อมทั้งเตรียมโค้ด SQL ที่ถูกต้องสมบูรณ์มอบให้ผู้ใช้งานเป็นคนนำไปรันเองใน phpMyAdmin เท่านั้น
- **กฎการเขียนปุ่มกด (Button Rule):** ปุ่มกดแบบ 3D Squircle จะต้องทำงานร่วมกับแท็ก HTML มาตรฐาน (`<a>` สำหรับเปลี่ยนหน้า และ `<button type="submit">` สำหรับส่งฟอร์ม) เสมอ เพื่อให้การส่งฟอร์มและการทำงานของเบราว์เซอร์ลื่นไหล ปลอดภัยจากปัญหา JavaScript ทำงานไม่ทัน (Race Conditions)
- **กฎความเข้ากันได้ของระบบหลังบ้าน (Admin UI Rule):** หน้าหลังบ้านทั้งหมดของ Admin (รายการหน้าเว็บ, หน้าสร้างหน้าเว็บ) จะไม่มีการโหลดแถบนำทาง (Navbar) และส่วนท้าย (Footer) เพื่อจำกัดพื้นที่ใช้งานให้กว้างที่สุดและแยกบทบาทการใช้งานของลูกค้าออกจากกันอย่างชัดเจน
- **Z-Index Hierarchy:** สำหรับหน้าเว็บฝั่งลูกค้า ส่วนของ Header (รวมถึง Hamburger menu และแถบนำทาง) จะต้องมี `z-index` สูงกว่า Footer เสมอ เพื่อป้องกันส่วนท้ายบดบังเมนูนำทางบนหน้าจอมือถือ
- **กฎการใช้ไอคอน (Icon Rule):** ให้อนุญาตการใช้อีโมจิ (Emoji) ดิบในส่วนตกแต่งหรือหัวข้อได้ตามปกติ **แต่ให้เปลี่ยนอีโมจิเป็นไฟล์ภาพ SVG เฉพาะในส่วนที่เป็น "ปุ่มกด (Button)" เท่านั้น** (โดยอ้างอิงจากโฟลเดอร์ `assets/icons/`) หากผู้ใช้งานต้องการให้แก้ไขหรือเปลี่ยน Emoji ในส่วนอื่นๆ เป็นรูปภาพเพิ่มเติม ผู้ใช้งานจะแจ้งให้ทราบเองเป็นกรณีไป
