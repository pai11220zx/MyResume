## Platform

web

## Users
- Tech Recruiters, Hiring Managers, and Engineering Leads evaluating candidates for Software Development and Automation internships.
- Peers, collaborators, and clients reviewing technical projects, source code, and development capabilities.

## Product Purpose
Provide a high-impact, interactive, and high-performance developer portfolio and resume for Purachet Aoborm (Pai). The site showcases technical projects, Computer Science coursework, skills, achievements, and provides a direct, validated contact channel for internship hiring opportunities.

## Positioning
An interactive, high-performance developer portfolio blending modern WebGL shaders (SoftAurora, GlowCursor) with accessible, high-contrast typography and scroll-driven GSAP animations, demonstrating both aesthetic design craft and engineering rigor.

## Operating Context
- Modern desktop, tablet, and mobile web browsers.
- Evaluated as a primary showcase of frontend craft, clean architecture, and full-stack integration capabilities (Supabase/PostgreSQL).

## Capabilities and Constraints
- Single Page Application (SPA) built with React 18, Vite, Tailwind CSS, GSAP, Framer Motion, and OGL.
- Full-stack contact messaging system with client validation and Supabase Row Level Security (RLS).
- Zero-latency page load with dynamic on-demand imports and GPU hardware acceleration.
- Technical constraints: Strictly adhere to database security standards (Rule 10) and git version control etiquette (Rule 11).

## Product Principles
1. **Speed & Smoothness First:** Instant load times, dynamic imports, and 60-120 FPS interaction with GPU acceleration.
2. **Authentic Craft:** Every project showcases genuine problem-solving, architectural challenges, and real code.
3. **Contrast & Readability:** Text and critical information must remain crisp and readable over dynamic WebGL backgrounds.
4. **Accessible Semantics:** Native semantic HTML, ARIA attributes, and uniform borders without visual clutter.

## Accessibility & Inclusion
- High-contrast text palettes (#FFFFFF, #E2E8F0, #CBD5E1) with drop-shadows on dark canvases.
- Semantic HTML tags, landmark regions, and fully accessible button/form labels.
